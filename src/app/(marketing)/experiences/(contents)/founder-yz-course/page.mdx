I founded and developed Yz-Course, an English-learning platform covering LMS, enrollment, learning progress, analytics, and transactions.

Built backend services with **Laravel 13 / PHP 8.4**, Sanctum auth, Laratrust RBAC, RESTful API and Lighthouse GraphQL. Designed data infrastructure with **PostgreSQL 16 + pgvector** and **Redis 7** for transactional data, cache, queues, semantic search, and RAG workflows.

---

## Frontend & Mobile

1. Primary web app with **Next.js 16 / React**, Redux Toolkit, Tailwind CSS, DaisyUI, TanStack Query, TipTap, and MUI.
2. Mobile experiences with **React Native**, React Navigation, Firebase Messaging, WebRTC, Redux Toolkit, and Socket.IO Client.
3. LMS workflows: courses, enrollment, learning progress, analytics, transactions.

---

## Integrations & Infrastructure

1. **Midtrans** payment gateway, webhooks, AWS S3, media processing, WhatsApp workflows, realtime services with Node.js + Socket.IO.
2. AI capabilities with **OpenAI, Gemini, Groq, Ollama**, embeddings, RAG, and semantic search for AI-assisted learning.
3. Production infra with **Docker Compose, Nginx / PHP-FPM, PM2, PostgreSQL streaming replica, Redis, Prometheus, Grafana**, healthchecks and resource limits.
4. Realtime discussion forum with Next.js + Laravel REST API + Node.js services.
